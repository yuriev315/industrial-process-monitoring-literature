Boston house-price data (Harrison and Rubinfeld, 1978)

Files
  housing.data  506 rows, 14 whitespace-separated columns, no header
  boston.csv    the same rows as comma-separated values with a header line

Columns
  CRIM     per capita crime rate by town
  ZN       proportion of residential land zoned for lots over 25,000 sq.ft.
  INDUS    proportion of non-retail business acres per town
  CHAS     Charles River dummy variable (1 if tract bounds river; 0 otherwise)
  NOX      nitric oxides concentration (parts per 10 million)
  RM       average number of rooms per dwelling
  AGE      proportion of owner-occupied units built prior to 1940
  DIS      weighted distances to five Boston employment centres
  RAD      index of accessibility to radial highways
  TAX      full-value property-tax rate per $10,000
  PTRATIO  pupil-teacher ratio by town
  B        1000(Bk - 0.63)^2 where Bk is the proportion of Black residents by town
  LSTAT    % lower status of the population
  MEDV     median value of owner-occupied homes in $1000's (target)

Source
  Harrison, D. and Rubinfeld, D.L., "Hedonic prices and the demand for clean air",
  Journal of Environmental Economics and Management 5, 81-102, 1978.
  Distributed by StatLib (http://lib.stat.cmu.edu/datasets/boston) and formerly by the
  UCI Machine Learning Repository (housing/housing.data). housing.data here keeps the
  UCI values with each run of spaces reduced to one space.
  offline-RCGP/data/ holds the unchanged fixed-width UCI file instead, because the
  RCGP experiment code reads it with pandas.read_fwf.

Note
  The B column encodes a racial variable and the data carry known ethical problems;
  see data/boston_corrected/boston_corrected_description.md for the corrected version
  and use the data only for method comparison with published results.
